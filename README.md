# yasa-rule-optimizer
A project focused on optimizing the rule generation logic of the YASA static analysis engine.

## Directory convention

- `apps/web/`: web frontend
- `apps/client/`: client application
- `yasa_engine/`: YASA engine base and runtime dependencies
- `yasa_engine/yasa-api-agent/`: backend API service
- `datasets/`: experiment datasets
- `prompts/`: prompt templates
- `workflows/`: experiment workflows
- `docs/`: project and experiment documents
