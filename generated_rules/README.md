# Generated Rules Directory

This directory contains rules generated by the LLM-assisted rule generation pipeline.

## Directory Structure

- `staging/`: Newly generated rules awaiting validation
- `candidate/`: Rules that passed validation and evaluation
- `production/`: Rules approved for production use

## Rule Lifecycle

1. **Generation**: LLM generates rule → saved to `staging/<ruleId>.json`
2. **Validation**: Schema + semantic validation
3. **Evaluation**: Test against benchmark cases → if metrics pass → move to `candidate/`
4. **Review**: Manual review → if approved → move to `production/`
5. **Integration**: Merge into official rule config files

## Metadata

Each rule file includes a `metadata` section tracking:
- `ruleId`: Unique identifier
- `generatedAt`: Timestamp
- `caseId`: Source vulnerability case
- `language`: Target language
- `vulnerabilityType`: Type of vulnerability detected
- `iterationRound`: Optimization iteration number
- `validationStatus`: Current validation state
- `evaluationMetrics`: Precision, recall, F1 scores
